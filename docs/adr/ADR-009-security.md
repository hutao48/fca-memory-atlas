# ADR-009：安全模型 —— 仅回环 + Bearer token + 审计 + 脱敏

- 状态：已接受（2026-11-12）
- 决策者：Lead（架构/安全）
- 关联：PUBLIC_INTERFACE_FREEZE.md §0/§7、ADR-007

## 背景

本地服务默认仅监听 127.0.0.1，不得默认暴露公网；需要本地身份验证、访问日志脱敏、请求追踪、事务保护。

## 决策

1. **网络面**：默认只绑定 `127.0.0.1`；若配置非回环地址需显式开关并打印高风险警告（Alpha 0.1 默认拒绝）。`/health` 免认证但只返回最小信息；其余全部 `Bearer` 认证。
2. **本地身份**：首次初始化生成 32 字节随机 token 写入 `<FCA_HOME>/config/runtime-token`（ACL 仅当前用户）；桌面与插件从该文件读取；轮换接口 `POST /api/v1/security/rotate-token`（Lead 可后续补）。
3. **追踪与审计**：每个请求生成 `trc_` ID 并在响应头回传；`audit_log` 记录操作主体、客户端类型、端点、对象、结果、耗时；不记录正文与 token。
4. **日志脱敏**：结构化 JSON 日志；对 `authorization`、`token`、`api_key`、`apiKey`、`password`、`secret` 等键与常见密钥模式（`sk-…`）做掩码；限制日志体积与轮转。
5. **输入安全**：统一 JSON schema 校验（类型/枚举/长度上限）、path 参数白名单（不拼接文件路径）、导入/恢复文件先校验再落盘；SQL 一律参数化。
6. **数据保护**：API Key AES-256-GCM + 受限 ACL；备份文件继承数据目录保护；导出需用户显式路径确认；硬删除需 `confirm=true` 且记录审计。
7. **依赖面**：运行时零第三方依赖，减少供应链风险。

## 后果

- 需要在使用文档中说明 token 位置与轮换、端口与数据目录的权限建议。
- 安全测试项：未带 token 401、错误 token 401、非回环绑定被拒、日志无敏感值、SQL 注入/路径穿越无效、超大 payload 413。
